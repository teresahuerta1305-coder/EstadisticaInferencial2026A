3. Hallazgos principales
- Predominan las casas de 3 habitaciones: 1,115 viviendas, aproximadamente el 55.6% del total.
- Hay una diferencia considerable entre el precio promedio y la mediana: esto sugiere que algunas propiedades de precio muy elevado aumentan el promedio.
- La superficie tiene una relación importante con el precio: la correlación entre ambas variables es de aproximadamente 0.443, lo que indica una asociación positiva moderada.
- La ubicación presenta mucha variedad: se identificaron 1,274 descripciones distintas. La categoría genérica “Casa en Venta Toluca De Lerdo, México” aparece 453 veces.
- Existen valores extremos: por ejemplo, una superficie de 11,111 m², 124 baños o un precio de 10,000,000. Estos registros necesitan revisión.
